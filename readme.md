# 🚗 AutoCare - Vehicle Service Management System

A modern and user-friendly **Vehicle Service Management System** designed to help automobile workshops manage customers, vehicles, service bookings, service history, and workshop reports from a single dashboard.

This project is developed as a **frontend-based web application** using HTML, CSS, and JavaScript. Data is stored in the browser using **Local Storage**, so no database or backend server is required for the current version.

---

## 📌 Project Overview

Vehicle service centers handle many customers, vehicles, service appointments, mechanics, service costs, and previous service records.

Managing all these details manually can be difficult and time-consuming.

The **AutoCare Vehicle Service Management System** provides a digital solution for managing:

- Customer information
- Vehicle information
- Service bookings
- Assigned mechanics
- Service status
- Service costs
- Service history
- Workshop information
- Reports and statistics
- Local browser data

---

## 🎯 Objectives

The main objectives of this project are:

1. To provide an easy-to-use interface for vehicle service center management.
2. To reduce manual record keeping.
3. To maintain customer and vehicle information digitally.
4. To manage service appointments efficiently.
5. To track service status and service history.
6. To calculate and display service-related statistics.
7. To store application data using browser Local Storage.
8. To provide a simple administrative login system.
